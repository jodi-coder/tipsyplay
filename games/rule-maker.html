📏 Rule Maker

👥 4–10🃏 Phone🎯 medium📏 rules
Non-alcoholic alternative (always fine): Slip-ups cost a point.
Host Game

You must be of legal drinking age in your location.

Setup

  1. Host a room. The phone deals the rules. No physical deck.
  2. Read the rule out loud once so the table shares it.
  3. Turn on non-alcoholic mode if a slip should only cost a point.

Rules

  1. The rule is live until the next card. Older rules do not stack.
  2. If you slip, take one small sip or lose a point.
  3. One slip per round, maximum. No waterfall, no chugging, no king's cup.
  4. Passing is always fine. You can sit a rule out.

Variations

  • Rules last two rounds instead of one. Still no stacking beyond that.
  • Mime round: the rule has to be followed silently.
  • The table may veto one rule a night and draw the spirit of a kinder one.
