Host Game

You must be of legal drinking age in your location.

Setup

  1. One person taps Host Game. Everyone else joins with the code on their own phone.
  2. Drinks are optional. Water and mocktails count the same.
  3. Pick a short round count. Five lines already make a mess.

Rules

  1. A starter line shows on every phone.
  2. Each player adds one short sentence.
  3. If the group groans, take one small sip or strike a 5-second pose. Passing is always fine.
  4. One optional sip per sentence, max. Nobody stacks extra.

Variations

  • Theme lock: every sentence has to include a word the host calls.
  • One-word chain: each person adds a single word.
  • Trailer voice: the host reads the finished chain like a movie ad.
