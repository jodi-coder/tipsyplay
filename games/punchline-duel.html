What is Punchline Duel?

Punchline Duel is TipsyPlay's answer-and-vote party game. Two players get the same funny prompt and each write an answer on their own phone. Everyone else votes for the funnier one, and the writer of the losing answer takes a drink or sits the sip out. It is an easy party game for adults that works for 3–12 players with no props.

Every phone shows the prompt and both answers at the same time, so remote joiners and couch hangouts stay in sync. Host a room, pass the code or QR, pick how many rounds, and let the duels rotate around the table.
